## What is SomiFlow?

SomiFlow is a no-code DeFi automation platform that allows users to create and manage complex financial strategies without writing a single line of code.

At its core, it provides a visual drag-and-drop workflow builder where users connect modular nodes to form automated pipelines. These workflows can represent actions such as:

* Automatically staking tokens on a schedule
* Rebalancing portfolios based on price triggers
* Consolidating assets across protocols
* Executing conditional DeFi strategies

SomiFlow operates on a non-custodial architecture. Users retain full control over their assets at all times. The platform never accesses private keys or seed phrases, ensuring secure execution without compromising ownership.
